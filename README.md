## Simple Interest Calculator

This project is a simple interest calculator implemented using a Bash shell script.

## Purpose

The Simple Interest Calculator calculates simple interest and total amount using the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest:

SI = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period

Total Amount = Principal + Simple Interest
